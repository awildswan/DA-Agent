# 0008. V2 数据地基：TPC-H + 数据源解绑 + 确定性度量基线

- **状态**：Accepted
- **日期**：2026-11-26

## 背景

V1 的命门：**真实数据能力为零**（只有 `db/sample.py` 7 行硬编码示例）；评测只有 Spider（通用 NL2SQL，测「SQL 写得对不对」）；打分是 LLM（不可复现，基线抖动 = 没法判断改动是进步还是噪声）。

## 决策

1. **数据集：TPC-H 作为「真实规模」的测试数据集**（DuckDB 内置 `tpch` 扩展 `dbgen(sf=0.01)` 生成，8 表星型，sf 可调）。它**不是绑定**——只是可选数据源之一。
2. **数据源解绑**：agent 不绑定任何单数据集；连接哪个库，就用哪个库的 schema（运行时 `list_tables` / `describe_table` 发现）。换数据集 = 换连接。
3. **度量基线确定性**：确定性检查做基线（可复现），LLM 打分只作语义辅助，**不做基线**。

## 后果

- 正面：能查真实规模数据（星型 JOIN）、换数据集即换连接、优化可对比（确定性基线）。
- 代价：`db/` 层要重写（连接管理 + 多表 schema + `SET TimeZone`）；确定性打分需先写检查项；评测要从 Spider 扩到 TPC-H 22 查询。
