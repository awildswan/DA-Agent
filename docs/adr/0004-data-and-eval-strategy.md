# 0004. 数据来源组合 + 两层评测标准

- **状态**：Accepted
- **日期**：2026-11-22

## 背景

无真实业务库；需要数据演示语义映射 / 口径 / 交付闸门，也需要评测标准。

## 决策

- **demo 数据**：Northwind / AdventureWorks（真实业务结构）+ 一层合成的「业务口径 + 陷阱」（时区漂移、同秒重复单、部门 ≠ 战区）。
- **评测两层**：L1 自制业务口径集（对齐 daw，金牌 = 直查真值）+ L2 Spider / BIRD 子集（SQL 回归，附污染声明）。
- **A/B 对照**：证明机制有效性（闸门 / 口径 / 自纠 开-关）。

## 后果

- 正面：业务语义 + 业界对标 + 机制有效性三层齐。
- 诚实边界：无真实业务库，验不了「真实口径对错」；L1 只证「自洽 + 守纪律 + 被兜底」。
