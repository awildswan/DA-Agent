# 0005. 补充会话状态 + 上下文管理到设计

- **状态**：Accepted
- **日期**：2026-11-24

## 背景

设计 14 环节覆盖了感知 / 行动 / 长期记忆（OKF），但缺两个 agent 必要组件：**会话短期记忆（多轮对话）** 与 **上下文管理（压缩 / 窗口）**。这两样在书目《深入理解 AI Agent》第 2 / 3 章有，当初写设计时没搬进来。

## 决策

新增 **⑮ 会话状态与上下文管理（贯穿全程）**，含三块：

1. 会话状态（短期记忆）——会话内消息历史 + 结构化状态，与长期记忆（OKF）分层；
2. 上下文管理（压缩 / 窗口）——静态/动态 prompt 分离（已有）+ 超长历史压缩 + 窗口裁剪；
3. 多轮状态机——澄清 / 确认 / 纠正做成显式状态（反问 → 等确认 → 继续），确认后才沉淀。

设计由「14 环节」更新为「15 环节」。

## 后果

- 正面：agent 四件套（感知 / 规划 / 行动 / 记忆）在设计上闭环；短期记忆与长期记忆分层清晰。
- 代价：实现复杂度上升（多轮状态机 + 压缩策略需真实数据调参，见 open-questions）。
