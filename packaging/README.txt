Data Analysis Agent (Standalone / Green)
========================================

1. Extract this folder anywhere.
2. Copy .env.example to .env inside the daagent-server\ folder and fill in your
   own DeepSeek API key (OPENAI_API_KEY). The .env is NOT bundled with this
   package, so you must provide your own.
3. Double-click daagent-desktop.exe to launch (a native WebView2 window opens).
4. First launch takes a few seconds while the local server starts.

If the window shows "connection refused", wait a few seconds and press F5, or
close and relaunch.
